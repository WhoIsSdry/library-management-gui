# 📚 Library Management GUI

A simple library management GUI built with Python.

## 📌 About the Project

Hi, I'm sdry, and this is a university project I built as a simple and user-friendly library management system.

The project provides a clean GUI for managing books and members, along with a dashboard that displays important library information and recent activities.

## ✨ Features

* 📊 Dashboard with library statistics
* 📚 Add and manage books
* 👥 Add and manage members
* 🔄 Borrow and return books
* 🔍 Search for books
* 📋 View recent library activities
* 🟢 Track book availability

## 📚 Books

Manage your library books with ease. Add new books, view their details and availability, search for books, and handle borrowing and returning operations.

## 👥 Members

Easily manage library members. Add new members and view essential information such as their name, ID, and phone number.

## 🛠️ Built With

* Python
* CustomTkinter

## 🎓 Project

This project was created as a university project to practice Python programming and GUI development.
